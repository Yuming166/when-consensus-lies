# Read-only implementation and evidence verification

## Verified from saved artifacts

- Ledger contains 6,675 records: 2,225 each for original/positive/negative; all HTTP 200; model identity is Qwen3.5-4B; hash-chain errors are empty; two records lack `parsed_json` and were retained without retry.
- The audited Curve implementation reports GroupKFold(5), 424 source groups, positive class `original_incorrect=1`, HGB seed 20260928, and source-group bootstrap B=2,000, seed 20260928.
- The implementation audit tests pass: named feature dimensions, independent arrays/no shared memory, negative-world invariance of two-world features, and preservation of curve features before/after fitting.
- The saved OOF arrays all have n=1,735, matching labels and groups; the four HGB predictions are in one audited OOF file, so the reported HGB comparisons use the same rows and labels.
- Static source review confirms the two-world vector is explicitly built from original/positive response quantities only, while curve features include negative response quantities. The code also constructs ordinary three-world and Curve feature matrices from the same parsed rows.
- The original V1 results are preserved and the audit’s pre/post report records the change: two-world AUROC 0.7837→0.7722; ordinary three-world unchanged at 0.7978; Curve 0.8092→0.8138. This is a versioned discrepancy, not silently corrected historical output.

## Not independently established

- OOF provenance cannot be reconstructed from OOF files alone: they do not embed the full feature matrix, fold assignment file, or per-row training log. The code/report/hash chain provide evidence, but not a cryptographic proof that every saved prediction was generated by the current source.
- The 50-item review directory contains a 50-item, response/label-blind packet and metadata (seed 20260928, 50 distinct source groups), but no reviewer identity source, completed form, disagreement log, or adjudication record was found in that directory. Therefore “50/50 VALID” is recorded only as project-lead reported, not independently verified by this audit.
- Reverse-world semantic/financial validity for all 2,225 candidates is not established by the 50 reported judgments.
