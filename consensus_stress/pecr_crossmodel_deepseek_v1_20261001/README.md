# DeepSeek cross-model PECR V1

This directory contains the protocol, collection code, frozen summaries, and analysis results for a pre-specified DeepSeek V4.1 Flash test of PECR bidirectional response curves on FinQA `dev_train`.

The API budget expired during the single-attempt run. The report therefore explicitly distinguishes the positive primary result on the retained strict subset from independent/full-cohort confirmation. Raw request/response ledgers and large row-level feature files are retained locally but excluded from GitHub because of size.

- `STATUS.md`
- `reports/FINAL_REPORT.md`
- `reports/COVERAGE_FLOW_DEEPSEEK.json`
- `protocol/PRE_CALL_PLAN.md` and both protocol amendments
- `results/within_deepseek/CURVE_HGB_AUDITED.json`
