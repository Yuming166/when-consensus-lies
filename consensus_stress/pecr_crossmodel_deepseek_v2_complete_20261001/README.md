# DeepSeek V4.1 Flash cross-model PECR — complete-attempt V2

This directory publishes the auditable, non-raw artifacts for the post-top-up **complete attempt** of the three-world PECR experiment with DeepSeek (`deepseek-flash`). V1 was preserved unchanged; V2 retried only the 2,682 slots whose V1 HTTP status was 429 or 402. No API key, raw ledger, raw response corpus, prompt/response cache, or execution log is included here.

## Scope and claim boundary

- **Claim supported:** on the strict complete-attempt cohort, the audited three-world Curve HGB is superior to the same-budget ordinary three-world HGB by a paired AUROC difference of **+0.0153** with source-group bootstrap 95% CI **[+0.0070, +0.0235]**.
- **Cohort:** 2,050 strict items from 2,225 requested construction items (92.13% item coverage; 448/453 source groups).
- **Data/setting:** FinQA `dev_train`; this is a cross-model robustness analysis, **not** an untouched independent holdout confirmation.
- **Primary labels:** `original_incorrect=1`; all methods use identical items, folds, response records, parser rules, and coverage.
- **Secondary transfer results are descriptive**, not evidence of relative model quality.
