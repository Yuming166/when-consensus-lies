# Decision — 多轴压力响应轮廓是否进论文（Agent W3）

- 日期：2026-09-14
- 判定规则（任务约定）：多轴组合相对 RS_q/BF_q **增量显著 = 进论文**；否则 **降为诊断图**。
- 依据：`stress_profile_analysis.md` + `stress_profile_results.json`（全部 post-hoc）。

## 证据摘要

1. **Task 2（多轴组合 vs RS_q/BF_q，HC）**
   - 冻结复现：Qwen RS_q AUROC 0.943 [0.924, 0.960]、Risk@80 0.846 [0.638, 0.981]；Ling AUROC 0.896 [0.875, 0.917]、Risk@80 0.422 [0.261, 0.587]。
   - 所有固定权重多轴组合的 ΔAUROC vs RS_q ≤ 0：Qwen `risk_rev_rem_para` -0.022 [-0.038, -0.006]、
     `risk_z3` -0.012 [-0.027, -0.000]（CI 上限 ≤ 0）；Ling 全部显著为负（`risk_rev_rem_para` -0.024 [-0.038, -0.011]）。
   - 加移除轴不稀释的组合 `risk_rsq_rem` 反而显著更差（Qwen -0.052 [-0.084, -0.021]；Ling -0.048 [-0.075, -0.025]）。
   - **拟合上限打平**：3 轴 OOF 逻辑回归 vs RS_q —— Qwen -0.001 [-0.006, 0.004]；Ling -0.005 [-0.013, 0.002]（CI 含 0）。
   - Risk@80 无任何显著增量（ΔRisk@80 CI 含 0 或为负）。
   → 多轴轮廓对 RS_q/BF_q **无显著增量**，且不是权重选择问题（拟合上限也打平）。

2. **Task 3（假阳性分解）**
   - 审稿质疑成立：正确 HC 面板中 `consensus-rigid` 占 Qwen 70/502（13.9%）、Ling 124/455（27.3%）；
     `fully-rigid` 占 Qwen 46/502（9.2%）、Ling 102/455（22.4%）。
   - 离散 removal 轴**不能**分开"正确刚性"与"错误刚性"：Qwen 0.501 [0.441, 0.557]（chance）；Ling 0.461 [0.434, 0.487]（低于 chance）；
     `fully-rigid` 两模型均为 0.500（rem 分布逐值相同）。
   - paraphrase 轴仅给出小的部分分离（consensus-rigid：Qwen 0.583 [0.521, 0.646]、Ling 0.604 [0.567, 0.642]）。
   - 连续 λ 移除曲线临界且样本极小（Qwen 120-pair：removal stress area 分离 0.624 [0.505, 0.754]，n=26/22）。
   → 多轴轮廓也**不能修复**单轴刚性信号的假阳性弱点。

## 判定：降为诊断图（不进主文评分贡献）

- 主评分**保持冻结 RS_q = −BF_q**（不改任何协议数字）；多轴轮廓不作为新评分/新启发式进入主文。
- 多轴轮廓降级为**补充诊断图 + post-hoc robustness 小节**（附录/补充材料）：
  1. 二维压力轮廓散点（反转刚性 vs 移除不稳，按正确性分组；`figures/axis_profile_scatter.png`）：
     展示"错误共识反转更刚 + 移除更不稳"的可复现反向签名（全 cohort 两模型，Task 1）。
  2. 一段诚实的假阳性边界：反转刚性轴有已知假阳性率（正确但不变：13.9%/27.3% consensus-rigid），
     removal 轴在 λ=1 无法分离这些假阳性，paraphrase 轴仅部分分离；
     RS_q 应表述为**有已知假阳性率的排序信号**而非机制声明。
  3. 引用 OOF 3 轴打平作为"该特征集合已近上限、无需更多轴"的负结果证据。
- 不进主文的理由（对应任务规则）：**增量不显著（且多数显著为负）** + 假阳性修复不成立。

## 建议的论文表述（一句话）

"移除/改写等附加压力轴在冻结 RS_q 之外不提供显著增量（OOF 3 轴打平），且无法修复反转刚性轴的
假阳性（正确但不变的面板占 13.9%/27.3%）；多轴行为作为诊断图报告，主评分保持 RS_q。"
