# PECR/CST examples and benchmark enhancement (2026-10-01)

This directory contains the zero-call audit and a separate LaTeX manuscript copy for the When Consensus Lies enhancement work.

The package preserves two contribution boundaries:

1. CST and PECR are complementary intervention-reliability tracks: construction validity, response selectivity, and original-answer error diagnosis. They are not combined into one score.
2. PECR is represented by an auditable bidirectional response curve. HistGradientBoosting is an implementation choice, not the claimed algorithmic contribution.

The included cases are internal descriptive candidates. Raw case JSONL, assistant responses, caches, and other source records are intentionally excluded because semantic review, complete CST prompts, and item-level redistribution authorization were not available. The package therefore does not claim public case confirmation or independent generalization.

No model, API, or training calls were made for this package. See `FINAL_REPORT.md`, `audit/AUDIT_SUMMARY.json`, and `reports/CLAIM_EVIDENCE.md` for counts and evidence boundaries.
