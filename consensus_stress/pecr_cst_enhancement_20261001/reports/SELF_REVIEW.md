# Five-dimension self-review

1. **Claim support:** contribution wording is limited to the intervention suite and PECR bidirectional representation; HGB is implementation.
2. **Data lineage:** selected rows retain source IDs, line locations, file hashes, edits, responses and parser/unit status.
3. **Validity:** mechanical construction, semantic validity, response class and original-error labels are kept separate.
4. **Reproducibility:** seeds, selection ranks, raw ledger checks, CST flip recomputation and zero-call counts are recorded.
5. **Writing and scope:** examples are descriptive; CST/PECR have no aggregate score; missing license/review/prompt evidence blocks public confirmation.
