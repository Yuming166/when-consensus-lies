# Phase history and final release scope

The package preserves earlier acceptance records as they existed, instead of
rewriting their history. The final aligned registry is defined by
`protocol/ALIGNED_TRACK_SPEC.json`, `MANIFEST.json`, `DATA_CARD.md`, the native
suite completion receipt and `acceptance/clean_refit_final/`.

| Preserved earlier record | Meaning when created | Current disposition |
|---|---|---|
| `protocol/RELEASE_SPEC.json` | First acceptance plan for old shared primary and existing native source comparison | Superseded for final aligned-track naming; old results are preserved |
| `protocol/METHODS.json` | Six method names/masks, five contrasts, existing 70-fit implementation plan | Names/masks/contrasts remain fixed; final aligned registry runs 90 fits |
| `reports/GENERATION_BINDING.md`, `audit/generation_binding_audit.json` | As-before Qwen/shared binding; no native Graph/three removal OOF yet | Historical inventory, not a statement that completed native methods are still missing |
| `coverage/attempted_frame.jsonl`/`.csv`, `SUMMARY.json` | As-before two-track source projection | Canonical final frame is `attempted_frame_final.jsonl`/`.csv` and `FINAL_SUMMARY.json` |
| `acceptance/failed_export_pass_v1/` | 70 fixed fits followed by interval-key export error | Retained failure; never labeled full entry success |
| `acceptance/clean_refit_existing_v2/` | Repaired 70-fit pass for both existing main suites and two native variants | All existing OOF/points/intervals exactly reproduced |

The final native suite adds four fixed variants with 20 fits, using the existing
native Raw/Curve predictions as its two previously reproduced references.
The final clean 90-fit entry independently reproduces all three six-method
tracks and the aliased native/shared contrast. These are suite completion and
reproducibility phases, without parameter, seed, sample or best-variant search.
No old source, primary or manuscript is replaced by the final registry.
