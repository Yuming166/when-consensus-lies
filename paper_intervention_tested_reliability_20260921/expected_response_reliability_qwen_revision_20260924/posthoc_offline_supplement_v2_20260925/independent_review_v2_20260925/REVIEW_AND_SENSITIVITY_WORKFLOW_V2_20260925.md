# Versioned review-result and sensitivity workflow v2

1. Reviewer returns the construction Stage-A CSV. Coordinator records reviewer identity/date and hashes the exact completed file. Do not edit after hashing. Run `make_construction_disagreement_v2.py`, supplying that digest and the sealed key. Output is a post-hoc per-item direction comparison; it reports minus/plus agreement separately and preserves reviewer reasoning. Then (and only then) disclose `STAGE_B_PRIORITY_CASES_SEALED_V2.md` and commission a second blind reviewer for BLK and AMT if feasible.
2. Reviewer returns the 28-item semantic form. Hash it before opening frozen labels for comparison. Preserve the 35 record-level queue rows (including repeats) separately from the 28 unique item judgments; compare labels once per unique item. Preserve the 35 queue records and their seven duplicate-ID entries; report both units (35 flags/records, 28 unique questions). Run `make_answer_label_comparison_v2.py` against the fixed label artifact and existing 139 merged scores, recording all three input hashes.
3. The comparison script emits disagreements and frozen-primary metrics unchanged. Its optional partial sensitivity treats only unequivocal reviewer `correct`/`incorrect` judgments among these 28 as alternate labels; ambiguous/unscorable judgments retain the frozen label and are explicitly counted. Any different adjudication rule must be specified and versioned before computing it. Report coverage and all disagreements; never overwrite labels, scores, manifest, ledger, or primary results.
4. If corrections/exclusions are contemplated, create a distinct sensitivity cohort and script that retains the full frozen result alongside it, lists every changed ID/reason, and recomputes paired metrics/intervals at matched support. No silent exclusion, sample replacement, threshold change, or claim of preregistered confirmation.

Both scripts are local/offline only. They require hashes to prevent post hoc editing; the human review itself is not complete until actual signed/identified review files are supplied.
